# End-Sem Quest 🍄

A Super Mario themed study checklist for end-sem exam prep. Tick a topic, collect a coin, and watch your progress bar grow.

**Live link:** https://daya-bahuguna.github.io/endsem-quest/

## What's inside

- Syllabus checklists for **Java**, **HTML & CSS** (plus Git and GitHub) and **JavaScript**
- Every syllabus section has its own checklist, organised by module
- Progress bars for each section and for the whole syllabus
- Your ticks are saved automatically in your browser, so they stay after you close the page

## How to use it

1. Open the live link above.
2. Pick a subject tab and tick topics as you finish them.
3. Come back any time. Your progress will still be there.

Note: progress is stored in your own browser, so each person has their own checklist. Clearing your browser data resets it.

## Built with

HTML, CSS and JavaScript. It's a single file with no installation needed.

## Run it yourself

Download `index.html` and open it in any browser.
